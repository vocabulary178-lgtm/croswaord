HOW TO TEST
1. Keep the images folder next to index.html.
2. Open index.html in a browser.
3. Choose A–E for each person and click Check answers.

HOW TO PUBLISH
Upload index.html AND the whole images folder to a static hosting service, such as GitHub Pages or Netlify. Do not rename the image files unless you also update their src paths in index.html. The file paths are relative, e.g. images/portrait_1_tom.png.

VIDEO
Paste a YouTube embed URL into the video field on the page, e.g. https://www.youtube.com/embed/VIDEO_ID. For a permanent published page, you may also hard-code the URL in the HTML if preferred.
